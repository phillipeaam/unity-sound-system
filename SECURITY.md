# Security Policy

Please do not report security vulnerabilities in public issues or discussions.

Use GitHub's private vulnerability reporting for this repository: [Report a vulnerability](https://github.com/phillipeaam/unity-sound-system/security/advisories/new). Include the affected package version, the impact, and steps to reproduce when possible.

If private vulnerability reporting is unavailable, contact the repository owner privately through [GitHub](https://github.com/phillipeaam) and avoid posting vulnerability details publicly.
